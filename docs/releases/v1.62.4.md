# Stratum v1.62.4

This release adopts the release contract (`contracts/RELEASE.md`,
STR-205): the versionCode is derived from the first-parent commit count
of the build checkout, and the internal-track upload attaches the
checked-in whatsnew and verifies itself by Play API read-back. There is
no earlier release tag, so the source set for these notes is the work
merged since the 1.62.3 internal deploy (versionCode 76): PRs #30, #31,
and #32.

## Fixes

- Plate-stack scanning accepts a stack with a single weight band
  (STR-244, PR #31). The scan returned valid data and the app rejected
  it, because a converted final tier carrying an upper bound failed the
  domain rule that the final tier is open-ended. The scan pipeline now
  normalizes a complete scan's final tier to open-ended inside the
  lattice, gated on no scanned rows having been dropped in conversion,
  and the vision prompt states the open-ended final band as an explicit
  rule.

## Internal

- Domain set-shape guardrails: `LiftSet` and `LoggedSet` share one set
  of shape rules (STR-168, PR #30). No behavior change.
- Release versioning is derived, not hand-bumped (STR-205). The 1.62.4
  versionName was set by PR #32 under the old hand-bump flow; its
  versionCode 77 is the last of the hand-set series.
