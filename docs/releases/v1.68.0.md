# Stratum v1.68.0

Minor bump under `contracts/RELEASE.md` §1.2: the range since
v1.67.0 adds user-visible capability in the workout screen:
live recommendations for assisted straight sets (STR-326),
a coach pane that fills from today's sets for lifts with no
history (STR-328), and selectable Overview rows that focus
their lift (STR-327). The versionCode is derived from the
first-parent commit count of the build checkout, as since
STR-205.

## What changed

- Live recommendations for assisted straight sets (STR-326,
  PR #150). Assisted lifts were scoped out of live
  recommendations in STR-29 and never brought back: logging a
  set on an assisted dip produced no recommendations for the
  following sets. A shared load-free recommendation policy
  now covers bodyweight and assisted straight sets. Logging
  the first assisted set anchors the block: the following
  sets carry the same assistance with reps projected from
  the logged set's reps and RIR through the fatigue curve.
  Logging a later set at the shown reps and RIR with a
  different assistance amount re-anchors the remaining sets
  on the new amount. Cold open stays unseeded, and
  next-session snapshot progression for assisted lifts is
  unchanged.
- Coach pane fills from today's sets (STR-328, PR #151). A
  lift with no previous session showed a blank Coach tab.
  Once a set is logged, the pane shows a Today section with
  bests from the current session (top set, total reps,
  estimated 1RM) and points the recommendation panel at the
  next incomplete set carrying a recommendation. Bodyweight
  sets count toward reps and carry no top set. The history
  and today bests share one derivation.
- Overview rows select and focus their lift (STR-327,
  PR #152). Overview lifts are cards with a status circle
  (check when the lift is complete), a sets progress bar
  under the stat tiles, and a Now pill on the current lift.
  Tapping a row scrolls the workout list to that lift and
  makes it the primary lift, so Coach follows it; the
  Overview tab stays selected.
