# Release notes

One file per release, named `v<versionName>.md`. The long-form notes for
a release live here; the short Play "what's new" text lives in
`distribution/whatsnew/en-US.txt`.

Both files are written in the release-prep PR and approved by merging
that PR. The drafting rules (source PRs only, facts only from those PRs,
the 500 character cap on the whatsnew) are in `contracts/RELEASE.md` §3.
