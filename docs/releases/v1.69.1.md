# Stratum v1.69.1

Patch bump under `contracts/RELEASE.md` §1.2. The range since
v1.69.0 adds no new thing a lifter uses. It moves the Android
build to current stable tools. The versionCode is derived from
the first-parent commit count of the build checkout, as since
STR-205.

## What changed

- Build tools (STR-313, PR #156). Android Gradle Plugin 9.5.2,
  Gradle 9.9.2, Kotlin 2.4.21, and Compose BOM 2026.11.01.
  The app compiles against Android SDK 37.2. targetSdk stays
  37. Training, logging, and progression behave the same.
- Glass blur (STR-313, PR #156). Glass panels use Haze 2.1.
  The blur on those panels changed, so the glass screenshot
  references were re-recorded. Other screenshots did not move.
