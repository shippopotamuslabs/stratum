# Stratum v1.64.0

Minor bump under `contracts/RELEASE.md` §1.2: the range since
v1.63.0 carries one user-visible feature, Sheet Mode, which
replaces the tabbed program editor with a single scrolling sheet
(STR-299, PRs #119–#126 and the follow-up fixes in #128). The
rest of the range is the STR-207 maintainability stack (PRs
#103–#118), which consolidates view-model state into single
derived flows with no behavior change. The versionCode is
derived from the first-parent commit count of the build
checkout, as since STR-205.

## What changed

- Sheet Mode (STR-299) is the release. The program editor now
  renders the whole program as one sheet: every workout is a
  section on a single scrolling page, and the workout strip at
  the top jumps to a section and follows the scroll (STR-300,
  STR-302). Each lift is one compact row; tapping it expands
  the full lift editor in place (STR-303).
- Lifts move between workouts with cut, copy, and paste
  (STR-304), and several lifts can be selected across workouts
  to edit sets, reps, and RIR together or delete them at once
  (STR-305). Undo restores exactly the lifts an operation
  changed and leaves later edits alone.
- A pinned volume strip shows per-muscle set totals for the
  whole program with fractional credit for secondary muscles,
  and a muscle by workout pivot table breaks the same totals
  down per workout (STR-306). Every program editor opens on
  the sheet; the tabbed editor is retired (STR-307).
- The follow-up fixes (PR #128) put per-muscle volume in the
  workout headers, keep the sheet still when a lift expands or
  collapses, give the undo snackbar a three-second timeout,
  restore the collapsed rows' full-height tap target and
  trailing menu, un-clip the pivot table, and make destructive
  actions read as destructive in both menus.
- The maintainability stack (PRs #103–#118) folds each
  screen's state into one derived ui-state flow composed in an
  observe use case, and adds detekt gates that keep view
  models to that shape. No user-visible behavior changes.
