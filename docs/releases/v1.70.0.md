# Stratum v1.70.0

Minor bump under `contracts/RELEASE.md` §1.2: the range since
v1.69.1 adds user-visible features on unfolded foldables
(STR-331, STR-332) and changes the settings import flow
(STR-333). The versionCode is derived from the first-parent
commit count of the build checkout, as since STR-205.

## What changed

- Two-pane Dashboard (STR-331, PR #158). Unfolded, the
  Dashboard keeps its board on the left and shows the selected
  muscle (8-week trend, per-lift sets per week, recent
  sessions) or lift (setup, bests, sessions) on the right.
  Folded layout is unchanged.
- Two-pane Program screen (STR-332, PR #159). Unfolded, the
  Program tab splits into the week and the selected day opened
  full with skip, swap, and start. The next workout day is
  marked and selected by default, and the pick survives folds
  and tab switches. Folded, half-opened, and narrow windows
  keep the single pane.
- Settings import opens the imported program (STR-333,
  PR #160). One imported program opens its editor, several
  open the Program Library, and zero imports, failures, and
  signed-out guidance stay on screen.
