# Stratum v1.62.10

Patch bump under `contracts/RELEASE.md` §1.2: the range since the
v1.62.9 tag carries one user-visible fix and a copy polish pass, and
adds nothing new a user can see or use. The versionCode is derived
from the first-parent commit count of the build checkout, as since
STR-205.

## What changed

- STR-280 (PR #92) fixed entitled users landing on the paywall after
  a transient entitlement read failure. On 2026-11-02 a single failed
  Play Integrity App Check token exchange left the launch-time
  Firestore entitlement listener without a valid token, and enforced
  Firestore denied it. The client treated that read failure as proof
  of no access: `EntitlementState.resolve` received `false` and
  returned `NotEntitled`. Complimentary access is now tri-state
  (`Granted` / `NotGranted` / `Unknown`): a failed read resolves to
  `Loading` while the listener retries on a 5-second cadence, a known
  Play purchase still entitles on its own, and the one-shot refresh
  behind paywall restore fails on an unverified read so restore
  reports an error with a retry instead of a definitive empty result.
- STR-184 through STR-187 (PRs #86–#89) replaced em dashes across
  core UI, domain, onboarding, program, settings, workout, and app
  copy.
- CI only: PR #84 (STR-278) split the solver nightly tests into
  their own workflow, PR #85 (STR-279) split the emulator tests into
  their own workflow, and PR #91 (CHOMP-58) bumped the chomp-reviewer
  pin to v2.1.2.
