# Stratum v1.65.0

Minor bump under `contracts/RELEASE.md` §1.2: the range since
v1.64.0 carries one user-visible feature, the sheet paste slot
(STR-317), plus three dogfood fixes from the first morning on
v1.64.0 (STR-314, STR-315, STR-316). The versionCode is derived
from the first-parent commit count of the build checkout, as
since STR-205.

## What changed

- Paste slot (STR-317, PR #136). A cut or copied lift pastes
  from a dashed slot row at the end of each workout's lift list,
  labeled with the held lift's name. The slot replaces the Paste
  here text button under the workout header; paste behavior and
  undo are unchanged, and the clipboard tray stays as it was.
- Pivot name column (STR-314, PR #135). The muscle by workout
  table's pinned name column now rides the same scroll state as
  the value columns, so the last muscles (Abductors, Adductors
  on a full 17-muscle program) keep their names beside their
  numbers at full scroll. An all-muscles pivot preview covers
  the overflow path in screenshot tests.
- Sheet row press highlight (STR-315, PR #133). Every bottom
  sheet option row now builds on one shared row surface that
  clips the pressed highlight and ripple to the row's rounded
  panel shape. Nine row implementations migrated; the lift swap
  and gym merge screenshot references were re-recorded for the
  corrected corner rendering.
- Destructive action last (STR-316, PR #134). The sheet workout
  menu now runs Rename, Reorder Lifts, Remove, and the history
  edit discard sheet puts Keep editing before Discard changes.
  An audit of every sheet option list found these two violations;
  the remaining lists already ended on their destructive action.
