# Stratum v1.65.1

Patch bump under `contracts/RELEASE.md` §1.2: the range since
v1.65.0 carries fixes only, two dogfood reports from Sean's
first day on v1.65.0 (STR-318, STR-319). The versionCode is
derived from the first-parent commit count of the build
checkout, as since STR-205.

## What changed

- Lift Options group dividers (STR-318, PR #138). The divider
  between action groups in the Lift Options sheet painted at
  1.06:1 against the sheet surface in Tonal dark, so the
  groups read as one list. The shared divider now uses the
  borderInteractive token (2.99:1 Tonal dark, 3.17:1 Tonal
  light, 5.38:1 Neo dark, 14.6:1 Neo light), and every Lift
  Options sheet gets the fix through the one component. Eight
  screenshot references re-recorded across the program and
  workout features.
- Sheet rest days (STR-319, PR #139). A rest day in Sheet
  Mode reused the lift row presentation, so rest days at the
  end of a workout read as two more lifts in that workout.
  The rest row now renders as a day band: an inset surface
  with a title-styled day label. Row order, the day menu, and
  the scroll anchor behavior are unchanged. Eight Sheet Mode
  screenshot references re-recorded.
