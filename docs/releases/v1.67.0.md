# Stratum v1.67.0

Minor bump under `contracts/RELEASE.md` §1.2: the range since
v1.66.0 adds a user-visible capability, the foldable two-pane
workout screen with coach pane (STR-323), plus a crash fix in
the program sheet (STR-324) and a dogfood fix batch for the
coach pane itself (STR-325). The versionCode is derived from
the first-parent commit count of the build checkout, as since
STR-205.

## What changed

- Two-pane workout screen with coach pane (STR-323,
  PR #147). On an unfolded foldable (flat fold, or any window
  at least 840dp wide with no fold) the workout screen
  splits: the logging screen stays on the left and a coach
  pane opens on the right, aligned to the hinge when the
  fold reports one. The pane carries a Coach / Overview /
  Rest segmented control, and the tab name appears only on
  the toggle. Coach follows the current lift with its
  configured target (rep range and RIR), last session set by
  set, bests tiles (top set, total reps, estimated 1RM), and
  the recommendation as an explainer: recommendations
  auto-apply to the set fields, so the panel narrates the
  change and never acts. Overview shows elapsed time, sets
  logged, volume, and estimated time remaining over the
  per-lift progress list. Rest shows the live countdown, the
  up-next set, and the timer controls. Logging a set opens
  Rest; the timer finishing or Skip returns to Coach;
  tapping a lift opens Coach for it. Folded and half-opened
  postures keep the single-pane screen.
- Move To keeps exactly one copy of a lift (STR-324,
  PR #146). The inspector's Move To passed the live lift
  through the paste-of-cut path, which skips removal: the
  lift landed in the target workout and stayed in its own,
  and moving it back inserted a second copy into the
  original workout, crashing the sheet list on the
  duplicate row key. Move To now runs the live move, which
  removes before inserting, guarded by a move-out-and-back
  regression test.
- Coach pane dogfood fixes (STR-325, PR #148). From Sean's
  device pass on the STR-323 build: the pane takes the
  status-bar top inset so the tab control clears the system
  bar; the Rest up-next detail reads the mapper's reps
  labels under its canonical concrete-reps gating, so a
  cold-start set shows its rep range; the Overview volume
  tile reads "0 lb" before anything is logged; Coach hides
  the last-session rows and bests tiles for a lift with no
  history; and the recommendation heading carries the
  signed change against last session's top set when there
  is one.
