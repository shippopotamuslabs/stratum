# Stratum v1.71.1

Patch bump under `contracts/RELEASE.md` §1.2: the range since
v1.71.0 is a single fix, with no new user-visible capability.
The versionCode is derived from the first-parent commit count
of the build checkout, as since STR-205.

## What changed

- Workout list scroll position survives fold and unfold
  (STR-336, PR #165). The shared two-pane container composed
  its main content from a different call site per posture, so
  folding or unfolding discarded the workout screen's list
  state and the lift list restarted at the top. The container
  now composes the main content in one fixed slot in every
  posture, and the list keeps its position in both directions.
  A core:ui regression test pins the retention across single,
  two-pane, and hinged postures.
