# Stratum v1.66.0

Minor bump under `contracts/RELEASE.md` §1.2: the range since
v1.65.1 adds a user-visible capability, the foldable two-pane
program sheet (STR-310), plus three fixes from Sean's dogfood
of that build on his Razr Fold (STR-320, STR-321, STR-322).
The versionCode is derived from the first-parent commit count
of the build checkout, as since STR-205.

## What changed

- Foldable two-pane program sheet (STR-310, PR #141). On an
  unfolded foldable (or any window at least 840dp wide with a
  flat fold), the program sheet splits: the sheet stays on the
  left and an inspector opens on the right. The inspector
  shows the program dashboard (weekly sets headline, volume
  bars, the muscle by workout pivot) by default, the tapped
  lift's full edit card with its muscle contribution panel
  and Move To controls when a lift is selected, and the
  clipboard tray in move and multi-select mode. Folding the
  device returns to the single-pane sheet with the same
  selection and edits. A top-bar Dashboard button returns the
  inspector to the dashboard in two-pane mode.
- Undo restores the inspector selection (STR-320, PR #142).
  Undoing a Move To restored the lift in the sheet and left
  the inspector pointing at the workout the lift had been
  moved to; a follow-up tap in that state crashed. The
  selection now reconciles whenever the program days change:
  it follows the lift to the day that holds it and clears
  when the lift is gone. Covered by unit tests at the
  selection level, including the reported move, undo, tap
  sequence's state shape.
- Inspector card treatment (STR-321, PR #143). The expanded
  lift card in the inspector ran edge to edge while the
  contribution block below it sat in an inset rounded panel.
  Both blocks now share one InspectorPanel treatment: inset,
  rounded, raised surface.
- Contribution header hierarchy (STR-322, PR #144). The
  "This lift contributes" header rendered at the muscle
  rows' size and weight in dark theme and blended in. The
  header now uses titleLarge, a clear step above the rows,
  in both themes.
