# Domain model classification inventory (STR-164)

Companion to `contracts/ARCHITECTURE.md` §3.1 (domain model policy). Generated by
enumerating every `data class` declaration in `:core:domain` production sources
(420 data classes at the time of writing) and classifying each into the
§3.1 classes: **A** aggregates / domain models (rich), **B** value objects (rich,
small), **C** domain services (procedural by design), **D** read models /
projections / results / wire types (data-only by design). Only A and B get
refactor chunks; each chunk in the STR-163 program cites its rows from the CSV.

The machine-readable inventory is `domain-model-classification-inventory.csv`
next to this file: one row per data class with its candidate invariants / state
meanings, the impossible-vs-legitimate decision, the producer changes that must
land in the same chunk as the model, and the owning chunk.
